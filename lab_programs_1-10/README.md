# Statistics with R Programming (ITA04) – Lab Programs 1–10

Each program has its R code (`programNN.R`) and an output screenshot (`programNN_output.png`).
`R_Lab_Programs_1-10.docx` collects all ten questions, code and outputs.

| # | Question |
|---|---|
| 1 | Create numeric, character, and logical vectors and display type and content |
| 2 | Create labeled matrices (5×4, 3×3, 2×2) filled by row/column |
| 3 | Create and display a 3D array with specified rows, columns, and tables |
| 4 | Create arrays from vectors with dimension names, print specific elements |
| 5 | Create and manipulate factor variables |
| 6 | Create a list containing vectors, matrices, and functions; display contents |
| 7 | Factors of a number, 10 random integers between -50 and 50, FizzBuzz 1–100 |
| 8 | Generate random numbers from a normal distribution; count occurrences |
| 9 | Create empty plots with specified axis limits |
| 10 | Create and explore a data frame `exam_data`: extract, add row/column, sort, save to file |

Run any program with `Rscript programNN.R` (tested on R 4.6.1).
